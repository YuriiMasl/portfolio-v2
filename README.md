# Портфолио Юрия — V2

Статическая русскоязычная страница разработчика сайтов для малого бизнеса. Без сборки, без API, без npm-зависимостей в рантайме. Хостинг — GitHub Pages: https://yuriimasl.github.io/portfolio-v2/

## Что на странице

- **Первый экран.** Компактная стеклянная шапка, крупный заголовок «Выдуваю сайты, как стекло», спокойный лид и одна главная кнопка «Обсудить проект в Telegram». Справа — сцена стеклодувной мастерской: металлическая стойка, стеклянная панель с реальным экраном демо-сайта и телефон. На телефоне сцена становится прямым кадром, копия остаётся крупной.
- **Витрина.** Три выбираемые работы сразу после героя: демо-сайты «Люблю, целую» и «Смена», концепт продукта LUMA. Метка стадии — в кадре, активная карточка подсвечивается.
- **Кейс «Люблю, целую».** Сравнение «было / стало» ползунком, список сделанного, ссылка на демо и честная оговорка: салон выдуман.
- **Кейс «Смена».** Доска с телефоном и десктопом, ссылка на рабочую страницу, список сделанного и оговорка о вымышленном бренде.
- **Кейс LUMA.** Отдельная интерактивная презентация концепта с записью, панелью студии и демо-данными.
- **Услуги, процесс, FAQ.** Три услуги на светлом костяном разрыве; шесть шагов с липким заголовком; семь нативных вопросов-ответов.
- **Обо мне и контакт.** Портрет, короткий текст, Telegram, ВКонтакте и телефон.

Отзывов, логотипов клиентов и бизнес-метрик на странице нет намеренно: их не существует. Портфолио показывает два демонстрационных сайта и один цифровой концепт, а не выдаёт их за запущенные клиентские проекты.

## Файлы

- `index.html` — разметка и весь текст.
- `redesign.css` — актуальная визуальная система: шапка, герой, витрина, кейсы, процесс, услуги, FAQ, контакты, адаптив, reduced motion.
- `hero.css` — композиция первого экрана и базовая сцена мастерской.
- `workshop.css` — палитра, типографика, кнопки, сравнение, доски кейсов.
- `portfolio-motion.js` — меню, активный кейс, свет за курсором, GSAP-раскрытия и дрейф героя.
- `workshop.js` — ползунок сравнения, полоса прогресса, закрытие меню по ссылке.
- `hero-layout.js`, `hero-cta.js` — геометрия сцены и поведение CTA.
- `assets/hero/` — подготовленные WebP-слои мастерской.
- `assets/` — скриншоты кейсов, портрет, альстромерия, шрифты в `assets/fonts/`.
- `cases/smena/` — опубликованная копия сайта «Смена».
- `cases/luma/` — самостоятельная презентация LUMA.
- `tools/check_portfolio.py` — 15 проверок контракта, локальных ресурсов, discovery-файлов и HTTP.
- `tools/serve.py` — локальный сервер только на loopback, выбирает свободный порт.
- `vendor/gsap.min.js`, `vendor/ScrollTrigger.min.js` — локальные GSAP 3.13, лицензия: https://gsap.com/standard-license
- `PRODUCT.md` — правда продукта: аудитория, позиционирование, ограничения.
- `DESIGN.md` — визуальная система: палитра, шкала, компоненты, движение, правила.
- `.impeccable/` — бриф поверхности, конфиг и рабочие артефакты Impeccable.
- `sitemap.xml`, `robots.txt` — индексация основной страницы; `editor.html` закрыт `noindex`.
- `REVIEW.md` — отчёты о проверках.

## Локальный запуск

Из папки `_gh/portfolio V2`:

```text
python tools/serve.py
```

Скрипт напечатает `Portfolio preview: http://127.0.0.1:N/` со свободным портом. Открыть этот адрес; остановка — Ctrl+C. Двойной клик по `index.html` не заменяет проверку по HTTP.

## Деплой

Пуш в ветку `main` репозитория `portfolio-v2` — GitHub Pages пересобирает страницу автоматически (source: `main`, `/`). Проверка: `gh api repos/YuriiMasl/portfolio-v2/pages`.
