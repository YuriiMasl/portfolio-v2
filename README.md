# Портфолио Юрия

Статическая русскоязычная страница разработчика сайтов для малого бизнеса. Без сборки, без API, без npm-зависимостей в рантайме. Хостинг — GitHub Pages: https://yuriimasl.github.io/portfolio/

## Что на странице

- Первый экран: послойная композиция стеклодувной мастерской — фон цеха, металлическая стойка и стеклянная панель с реальным скриншотом демо-кейса. Слева предложение для малого бизнеса, стеклянная кнопка «Написать в Telegram» ведёт к прямому контакту, текстовая ссылка «Смотреть проекты» — к витрине. На телефоне остаётся прямой кадр работы; меню открывает проекты, услуги, процесс, вопросы и контакты.
- Витрина из трёх выбираемых работ сразу после первого экрана: два демо-сайта и продукт-концепт LUMA; миниатюра ведёт к подробному кейсу.
- Кейс «Люблю, целую»: сравнение «было / стало» ползунком, список сделанного, честная оговорка о стадии работы.
- Кейс «Смена»: доска с телефоном и десктопом, ссылка на рабочую страницу, список сделанного и честная оговорка о вымышленном бренде.
- Кейс LUMA: отдельная интерактивная презентация SaaS-концепта с онлайн-записью, панелью управления и честно обозначенными демо-данными.
- Процесс работы: разбор задачи, форма, сборка, отжиг.
- Сайт под ключ, каталог и редизайн; процесс, FAQ, портрет и контакты (Telegram @IOpaWho, ВКонтакте, телефон).

Отзывов, логотипов клиентов и бизнес-метрик на странице нет намеренно: их не существует. Портфолио показывает два демонстрационных сайта и один цифровой продукт-концепт, а не выдаёт их за запущенные клиентские проекты.

## Файлы

- `index.html` — разметка и весь текст.
- `workshop.css` — оформление: палитра, типографика, сетка, компоненты, адаптив.
- `hero.css` — отдельная композиция первого экрана, привязанная к геометрии стойки; адаптация 390/768/1440 px.
- `workshop.js` — ползунок сравнения, полоса прогресса и необязательное появление нижних разделов (GSAP). Прокрутка нативная, панели не парят и не съезжают со стойки.
- `assets/hero/` — подготовленные WebP-копии слоёв из соседней папки `../ассеты`. Исходные PNG и скриншоты не изменены.
- `tools/build_hero_assets.py` — воспроизводимая подготовка слоёв и наложение мобильного скриншота на корпус телефона (Pillow).
- `tools/check_portfolio.py` — актуальные проверки hero, локальных ресурсов, контактов, якорей и HTTP.
- `assets/` — скриншоты кейсов, портрет, иллюстрация альстромерии, шрифты в `assets/fonts/`.
- `assets/smena-hero.webp`, `assets/smena-mobile.webp` — превью второго кейса, 1430×900 и 390×844.
- `cases/smena/` — опубликованная копия сайта «Смена» (HTML, CSS, JS, локальные шрифты и фотографии).
- `cases/luma/` — самостоятельная презентация LUMA: запись клиента, панель студии, локальное демо-хранилище и экранные снимки интерфейса.
- `tools/sync_smena.py` — пересобирает `cases/smena/` из `../../site_smena`; не копирует `.impeccable`, `PRODUCT.md`, `DESIGN.md` и `README.md`.
- `vendor/gsap.min.js`, `vendor/ScrollTrigger.min.js` — локальные GSAP 3.13, лицензия: https://gsap.com/standard-license
- `PRODUCT.md` — правда продукта: аудитория, позиционирование, ограничения.
- `DESIGN.md` — визуальная система: палитра, шкала шрифтов, компоненты, движение, правила.
- `.impeccable/` — рабочие артефакты Impeccable: бриф поверхности, конфиг, токены, скриншоты проверки.
- `_legacy/` — предыдущая версия страницы и её проверочные скрипты, сохранены для истории.

## Локальный запуск

Из папки `_gh/portfolio`:

```text
skpy tools/serve.py
```

Скрипт напечатает `Portfolio preview: http://127.0.0.1:N/` со свободным портом. Открыть этот адрес; остановка — Ctrl+C. Двойной клик по `index.html` не заменяет проверку по HTTP.

## Деплой

Пуш в ветку `main` — GitHub Pages пересобирает страницу автоматически (source: `main`, `/`). Проверка через `gh api repos/<owner>/portfolio/pages`.

Проверка локальной сборки 19.11.2026:

- Браузер: панель и клиентская запись LUMA просмотрены на 1440, 1280, 768 и 375 px; горизонтального переполнения нет, консоль без ошибок. На телефоне видны все семь пунктов панели, включая «Настройки»; имя студии сохраняется, заголовок занимает две строки.
- Пройдена запись от выбора услуги до подтверждения. На узком экране каждая запись раскрывается из карточки; название и цена сохранены в истории после удаления услуги, а недельный план не меняется. В месячном календаре «+ ещё» открывает все записи выбранного дня.
- Контраст подписей, заголовков таблицы, пояснений в карточках и подвала — от 4.8:1; кнопка первого шага возвращает на главную страницу студии. Восстановлены исходные демо-данные.
- Календарь проверен в месячном, недельном и дневном видах. Восемь актуальных JPEG-снимков лежат в `cases/luma/screenshots/`; превью панели показано на главной портфолио.
- `tools/check_portfolio.py http://127.0.0.1:50225/` через встроенный Python: 13 тестов — `OK`; 37 HTTP-ресурсов, 13 ресурсов LUMA и 6 ресурсов «Смены».
- Физический телефон, отключённый JavaScript и реальный backend не проверялись. Проект остаётся локальной концепцией; повторная проверка лида отложена по просьбе заказчика, деплой и push не выполнялись.
