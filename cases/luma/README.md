# LUMA

Интерактивный продуктовый концепт для небольшой студии: клиентская онлайн-запись и рабочая панель владельца. Это третий проект в портфолио и самостоятельная визуальная система, не связанная с макетами магазина и кофейни.

## Запуск

Откройте `index.html` через локальный HTTP-сервер из корня `_gh/portfolio`. Сборка и сторонние зависимости не нужны. Страница также рассчитана на публикацию как статическая папка внутри GitHub Pages.

## Что работает

- Переключение между панелью и клиентской записью.
- Стартовая страница студии с услугами, командой, адресом и переходом к записи.
- Пошаговый выбор услуги, специалиста, даты, свободного времени и контактов.
- Валидация формы и экран подтверждения.
- Разделы панели: обзор, календарь, записи, клиенты, услуги, команда и настройки.
- Поиск и фильтры, карточки истории, изменение статуса, отмена и удаление записей.
- Создание, изменение и удаление услуг; редактирование профилей команды.
- Сохранение изменений в `localStorage`.
- Авторские векторные портреты команды в интерфейсе.

Имена, записи и суммы вымышлены и нужны только для демонстрации. Данные не отправляются на сервер, уведомления и реальные сообщения не отправляются.

## Экранные снимки

Папка `screenshots/` содержит восемь снимков основных экранов, открытых в браузере: обзор, календарь месяца и дня, список записей на компьютере и телефоне, а также шаг выбора услуги и главную страницу клиентской записи.
